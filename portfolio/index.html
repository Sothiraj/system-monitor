01 / about

Engineer by degree,
adversary by training.

I'm YOUR NAME, a Computer Science & Engineering graduate from Salem, Tamil Nadu, who spent four years taking things apart — first C compilers and packet captures, then web applications, Active Directory forests and the cloud tenants that host them.

My day-one instinct is to read the source, map the trust boundaries and ask what the developer assumed that isn't true. My second instinct is to write it down clearly enough that a busy engineering team can fix it in one sprint. That combination — attacker's mindset, engineer's empathy, documentation a manager can forward to leadership — is what I bring to a security team.

Alongside offensive work I build and operate defensive tooling: log pipelines into a SIEM, Sigma rules with tests behind them, alert triage runbooks, and small Python tools that remove the boring 80% of a job. I run a homelab as a full-time playground — isolated VLANs, a rebuilt domain every Sunday, and a monitoring stack that has caught me many times.

“Access is a privilege, not a right. Data is somebody's life. Exploit responsibly, patch completely, disclose clearly.”
